# 手机端 UI 风格规范

## 当前网页原型补充（2026-10-14，优先于下方历史规格）

最新调整：分析指标保留 18px 细线图标，选中时使用极浅蓝底、细浅蓝边和蓝色图标，文字保持深色，不加小黑点。探索需求日历用数字后的 34px 小圆形底色表示需求：低需求无底色，中高需求采用两级浅蓝；不使用短线或整格填色。选中日期用深灰黑圆形白字，与首页呼应。

选中态规则：首页和探索页选中日期保持深色，7/28 天切换采用深色选中胶囊；分析指标采用浅蓝选中底色。蓝色突出执行操作，柔和彩色用于数据。键盘焦点保留清晰的蓝色轮廓，与选中状态区分。

本轮视觉统一：以用户认可的首页为基准。首页渐变保持原配色并提亮底色；其他页区块标题统一 20px/500，任务标题 18px，正文 13–14px。普通卡片沿用首页的 24px 圆角、白色材质和底部轻阴影。分析选中态为极浅蓝底和细边线，决策卡用白底，仅优先操作按钮突出蓝色。“我的”采用白色分组设置列表，编辑热区至少 44px。优先执行本段规格，后面的 22px 标题规格已替代。

- 当前为 frontend 下的五页 Next.js 原型。历史的蓝色首页、纯图标导航和无阴影卡片规格已被后续用户选择替代。
- 首页保留柔和暖粉紫渐变；工作、分析、探索、我的统一使用 #f7f8f9 底色。底部导航保留文字与浅蓝选中态。
- 使用 Outfit，中文优先 PingFang SC / Microsoft YaHei。主文字 #202124，辅助文字 #61656d，操作按钮蓝色。
- 功能页主标题 28px，区块标题 22px，任务卡标题 19px，正文 13–14px。首页问候语保留 40px。
- 普通卡片圆角 24px，半透明白色、细白边、轻微底部阴影；通过 native-home.css 共享变量统一。分析详情与上方指标左右对齐。
- 分析指标只显示一组摘要与一个当前详情区域；保留点选提示、查看详情箭头及选中态，避免重复大数字。
- 首页待办来自工作页入住／退款处理状态。推广在探索页；满意度及评价在分析页。

以下为早期设计记录，冲突时以上述补充及用户最新指示为准。

版本：v1.2 · 更新日期：2026-09-18  
状态：当前设计基线，允许继续修改。本文面向没有历史对话的新设计者或开发者。

## 1. 使用方式与项目约束

在设计或修改界面前，先阅读本文顶部的当前网页原型补充、`课程背景.md` 与 `docs/PRD.md`。下方 2026-09 的内容是历史记录；产品范围以新版 PRD 为准。课程排期不放进产品界面。

- 产品面向小型民宿经营者，包含咨询与评价、经营分析、内容推广三个核心方向。
- 手机端优先，默认英文，支持中文切换；与用户沟通及项目文档使用中文。
- 名称和 App 图标尚未决定。当前首页不显示品牌名称、图标或品牌占位符。
- 目前只有首页风格原型；其他功能入口仍为说明弹窗。不能将原型描述为已实现登录、真实分析或 OTA 接入。
- 所有经营数字、客人消息、预订记录均为示例，界面保留 Demo data 等标注。
- 用户新的明确修改优先于本文；修改后更新本文，使其始终描述最终方案。

## 2. 视觉目标

整体是轻盈、平面、浅蓝色的移动经营工作台：柔和蓝色渐变背景，白色卡片，圆形日期，细线图标，大号白色问候语，统一中性深灰正文，以及无文字的半透明磨砂底部导航。

最接近的参考是用户提供的三联手机设计图：蓝色欢迎页、白色数据卡片、轻细的图表与磨砂胶囊导航。该图片是方向参考，并非要求复制其中的财务业务或英文文案。即使没有参考图片，也应能按以下规格还原。

不要恢复早期版本的黄、粉大色块、黑色大导航胶囊、拉长的日期胶囊、蓝灰色正文或顶部品牌栏。卡片也不应有厚描边、边缘高光、立体倒角或明显投影。

## 3. 颜色与材质

| 用途 | 当前值 | 说明 |
| --- | --- | --- |
| 页面背景 | `linear-gradient(125deg, #A9CCE7 0%, #C7DEF0 32%, #E7F0F7 65%, #F0F5F9 100%)` | 上方浅蓝，向下逐渐变浅；不是蓝色图片背景 |
| 所有深色文字 | `#3B3E42` | 标题、正文、日期、按钮文字、辅助文案统一此色；用大小与字重区分层级，不混入黑色或蓝灰色 |
| 问候语及其副文案 | `#FFFFFF` | 仅这个头部文案区使用白字；月份已经恢复深灰 |
| 普通卡片 | `rgba(255,255,255,.90)` | 平面白色，无描边、无投影 |
| 经营建议方卡 | `rgba(239,248,253,.94)` | 比普通白卡略偏浅蓝 |
| 日程气泡 | `rgba(255,255,255,.95)` | 裁切式露出，不是覆盖全屏的弹窗 |
| 普通日期圆形 | `rgba(255,255,255,.38)` | 圆形内深灰文字 |
| 日期选中背景 | `#35434E` | 白色数字 |
| 导航选中背景 | `#343B45` | 白色图标 |
| 导航磨砂底色 | `rgba(242,246,249,.60)` | `backdrop-filter: blur(26px) saturate(115%)`，同时设置 WebKit 前缀 |
| 灰色滑动提示 | `#8A99A5` | 细小上向折线，非彩色按钮 |
| 次级按钮背景 | `#EAF1F6` | 深灰文字、胶囊形 |

磨砂导航必须是平面的：`border: 0; box-shadow: none`。背景内容经过时可透出模糊色彩，不做玻璃边缘反光。

## 4. 字体与字号

英文字体使用 **Outfit**，中文回退至 `PingFang SC`、`Microsoft YaHei`、`sans-serif`。Outfit 是贴近参考图的替代字体；没有确认参考图的真实字体名称，不能声称已识别为同款。

字体文件在 `prototype/fonts/Outfit.ttf`，可变字重 100–900，许可证为旁边的 `OFL.txt`。默认正文 400。使用随项目提供的字体，不依赖用户设备安装字体或外部在线字体服务。

| 元素 | CSS 规格 |
| --- | --- |
| 问候语 Hi, Alex. | 50px / 400，行高 1.12，字距 -1.8px，白色 |
| 问候副文案 | 12px / 400，白色 |
| 月份 September 2026 | 15px / 500，字距 -0.2px，深灰 |
| 首页区块标题 | 18px / 400，字距 -0.4px |
| 日期数字 | 15px / 500 |
| 星期 | 10px / 400 |
| 小组件名称 | 11px / 400 |
| 入住率数字 | 30px / 400；百分号 20px |
| 建议小标题 | 16px / 400，行高 1.2 |
| 建议正文 | 10px / 400，行高 1.35 |
| 任务卡标题、说明 | 14px / 400、11px / 400 |

当前方形小组件中的数据说明为 8px、横轴标记为 7px，是原型当前值。真实手机用户测试若难以阅读，应先减少文字，再与用户确认放大字号；不要缩小所有正文来硬塞内容。

## 5. 手机首页结构与尺寸

布局宽度以真实手机视口为准，重点检查 390px，兼容 320px–430px。页面最大宽度 430px；电脑上居中显示是预览外壳，不代表产品改为桌面端。全局禁止横向溢出，只有日期条可横向滚动。

```text
                              中文  [头像]
Hi, Alex.                     ← 单独下一行、大号白字
A little clarity for your day.

[日程气泡：默认完全隐藏，拖动时在此按比例露出]

September 2026     ˄            Demo data
 Mon  Tue  Wed  Thu  Fri  Sat  Sun …
 (14) (15) (16) (17) (18) (19) (20)  ← 圆形，可横滑

Your stay at a glance          This week · Sample
┌────────────────┐ ┌────────────────┐
│ Occupancy    ↗ │ │ AI insight   ✧ │
│ 70%            │ │ 简短经营建议   │
│ 细线图表       │ │ View suggestion│
└────────────────┘ └────────────────┘
Ready when you are                         2 items
[客人咨询卡片，Draft a reply]
[已存推广草稿，Continue draft]

           (⌂   消息   分析   内容   我的) ← 图标，无文字
```

- 头部边距左右 22px；顶部 `18px + safe-area-inset-top`。320px 窄屏左右 17px。
- 头像和语言切换右对齐，语言在头像左侧。头像 44×44px，语言按钮高度 44px。
- 头像行与问候语之间 12px；问候区下方约 22px。不得把问候语重新与头像并排。
- 月份紧靠日期区，标题行下间距 4px。灰色上滑提示在月份附近居中，不单独占据一大段空白。
- 日期圆形 42×42px，不因选中而加宽；日期单元间隔 11px。星期在圆形上方，已有安排以 4px 小圆点提示。
- 日历下不再出现单独的横向拖动条或 Show schedule 按钮。
- 内容区左右 16px，窄屏 12px。两个经营小组件等宽并排，间隔 10px（窄屏 8px）。
- 两个小组件是真正的圆角方形：`aspect-ratio:1`，圆角 20px，内边距 14px（窄屏 11px），而非高长胶囊。
- 在 390px 视口中每个方卡约 174×174px。建议文案需简短，避免裁切；窄屏建议标题可降至 14px。
- 下方任务卡为整行圆角矩形：圆角 26px，内边距 18px，卡片间隔 10px。
- 页面底部预留约 110px，保证最后一项可滚动到导航上方。

## 6. 图表与小组件

左卡显示入住率，右卡显示与数据相关的经营建议；整个卡片可点击，目标为经营分析。现有原型入口仍显示说明弹窗，不假装已完成分析页面。

图表使用清晰的实心柱状图，七根柱分别对应一周七天。柱间距 5px，各柱等宽，顶部圆角 3px；普通柱为 #BDD5C0，最后一柱为 #809EAC，无阴影。用户因细线版本不清晰，已明确要求恢复实心柱；不要再按参考图自动改回细线。

当前示例：七天入住率为 50%、60%、60%、70%、80%、100%、70%，每日 10 可售间夜，合计 49 / 70 间夜，即 70%。标签对应真实示例数值，改变图表时同步修改汇总，不能只为了好看编造相互矛盾的数据。

建议不是日历待办。AI 建议留在经营建议卡片，咨询处理和已有草稿留在下方任务区。

## 7. 底部导航：必须保留的细节

- 五个入口：Home、Replies、Insights、Content、Profile。只显示图标，不显示文字；保留对应的 `aria-label`。
- 胶囊宽度 `min(270px, 100vw - 96px)`，高度 44px，上下内边距 0。
- 悬浮位置：`bottom: calc(28px + env(safe-area-inset-bottom, 0px))`，水平居中。
- 选中圆形 44×44px，与导航完全等高；顶部和底部无留白。首尾项选中时圆形贴合胶囊端部。
- 图标 19×19px，线宽约 1.45px，未选中深灰，选中白色。
- 无边框、无内高光、无投影；半透明背景必须实际模糊后方内容。

## 8. 日程交互：跟手查看，松手隐藏

这是用户明确确认的最终行为，不要改回点击开关、固定展开或超过阈值自动吸附。

1. 默认日程气泡高度为 0，透明度为 0，不占布局空间。
2. 日程在问候区之后、月份与日期区之前出现；气泡内部不重复显示日期标题，不显示顶部小横条。头部取消最小高度，内边距上 10px、下 2px；日程行上下内边距 10px，详情底部内边距 10px。月份附近的灰色上向提示图标保留。
3. 在月份附近灰色提示处按住向上拖动，或在页面顶部从日历下方内容区向下拉动，可临时查看日程。
4. 展示高度随有效拖动距离连续改变，拖动 40px 就露出约 40px，拖动 90px 就露出约 90px。最多露出完整内容，不在阈值后自动打开。
5. 透明度随露出程度增长：当前实现 `min(1, height / 100)`。周围内容随高度变化移动，日程被容器裁切。
6. 松手或手势取消后自动收回：高度 260ms、透明度 220ms、间距 260ms，缓动 `ease`。不保持半开或全开。
7. 气泡仅显示已有入住、退房等日程，示例含时间、事项、房号；无安排写 `No events / 无日程`。不提供自定义备忘录、勾选待办或新建日程功能。
8. 日期横滑应保持正常；从内容区下拉只在页面滚动到顶部时触发，避免抢占常规滚动。拖动结束不得误触卡片链接。
9. 支持鼠标拖动。键盘辅助操作可在提示获得焦点后按住空格/Enter 查看，松开隐藏。

## 9. 动效

- 经营和任务卡片第一次进入视野时，从下方 14px 轻移至原位，透明度 0→1，450ms ease，只播放一次。
- 日期颜色切换约 200ms。不要使用大幅弹跳、闪烁或持续循环动画。
- 用户开启减少动态效果时，关闭非必要位移动效；内容仍须正常可见。
- 截图前等待字体加载和渐入完成，避免将加载期间的空白卡片误判为最终页面。

## 10. 文件、维护与验收

### 文件职责

- `prototype/index.html`：基础页面、图标和共用弹窗。它还包含早期样式与渲染函数。
- `prototype/home.css`：当前首页的实际覆盖样式。
- `prototype/home.js`：当前首页渲染、语言、日期、跟手日程与滚动动画。
- `prototype/fonts/Outfit.ttf`、`OFL.txt`：字体与许可证。
- `手机首页预览.html`：交付给手机的单文件，内嵌 CSS、JS、Base64 字体与字体许可证，可离线使用。

当前 CSS 存在迭代覆盖，必须按最终级联后的计算样式核对，不可照抄早期黑色导航或白色月份规则。实现重构可以清理重复代码，但应保持上述最终效果。

### 每次修改步骤

1. 根据用户本次修改更新相关源文件；不要只改单文件导出，否则下次导出会覆盖。
2. 同步更新本文对应章节和下方变更记录；已废弃的方案仅保留在 Git 历史，不与现行规则并列。
3. 重新合并单文件：将 index.html 中加载 home.css 和 home.js 的位置替换为内嵌内容，将字体 URL 替换为字体 Base64 data URI，保留 OFL 许可证。
4. 同时检查网页预览和离线 HTML；本地地址只是开发服务器，不是发布网站。

### 最小验收清单

- 390px 与 320px 宽度无页面横向溢出；中英文无重叠、裁切。
- Outfit 成功加载；头部问候白色、月份深灰，深色文字统一。
- 日期为圆形；两张经营卡片为方形；导航为平面磨砂、无文字、选中态无上下空隙。
- 日程默认完全隐藏，连续拖动展示量不同，松手回零；气泡位于日期上方且没有重复日期标题。
- 横向日期滑动、选日期、语言切换、普通纵向滚动及卡片入口可用。
- 离线打开单文件时样式、字体和交互不依赖额外下载。
