# Home greeting assistant

The existing greeting becomes an inline assistant. Tap the greeting or Ask AI to expand it; close or press Escape within the assistant to restore it. No extra bottom assistant entry is added.

Three initial suggestions: weekly performance, tasks needing attention, promotion draft. Free text uses deterministic bilingual keyword routing; unsupported questions explicitly explain that live AI is not connected. Responses link to Analysis, Work, promotion review or Explore. Task counts read current Work state. No network/model calls or automatic external actions.

Home retains calendar peek, compact occupancy bars, two overview widgets, pending task summaries and recent activity. The insight is shortened to weekday vs weekend occupancy. Font, gradient and navigation are preserved. UI_STYLE.md is not updated.

Validation: qa-assistant.cjs covers expand/collapse, keyboard, safe text, sample responses, route handoffs, task counts, Chinese and narrow widths. qa-analysis.cjs verifies existing analysis and Home links. The single-file preview is generated by export-preview.ps1.
