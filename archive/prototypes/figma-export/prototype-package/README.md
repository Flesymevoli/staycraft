## 使用方法

双击 `index.html` 即可开始预览（无需联网）：

- 顶部按钮：打开完整交互原型（五页可点击、语言切换、日程展开等均可操作）；
- 五张卡片：分别直达 Home / Work / Analysis / Explore / Mine 交互页；
- `pages/` 目录：五页的整页高清长图（宽 390px，供汇报或归档用）。
