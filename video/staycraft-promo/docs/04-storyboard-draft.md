## 0. 使用说明

- 本分镜把 02 的 21 个文案场景合并为 **16 镜**；合并依据是"一镜一个主动作 + 一个信息点"，映射表见 §8。
- 时间全部为 **帧**（30fps），秒数保留 0.5s 精度；所有镜界都是 **15f 的整数倍**（120BPM 的半拍），BGM 实测后允许 ±6f 吸附，**五幕边界与 brand hold 不动**。
- 每镜只允许 **一个主动作（主角手法）**；主表"镜头卡候选与变体"列写的是配方卡与 style-key，详细参数在 §3 逐镜卡与对应 demo TSX 中核对，**不得凭卡名新写**（pipeline 阶段 5 硬规则）。
- 每个信息落定点后 **≥30f 静止**（§5 预算表）；品牌字标两处 hold：S02 ≥30f、S16 ≥50f。
- 全片整画面级冲击 **2 处**（S02 冲白、S16 logo 脉冲），其余只在元素层（R4）。
- 验收帧：每镜 2 个绝对帧号，出 out/qa/ 静帧；另加成片抽帧回看。

### 1.2 音乐与节拍假设

- BGM 方向（02/00）：强鼓点电子底（tech-house 类）；skill 提供 5 首 Mixkit 备选，由 Lead 选曲并做 librosa 节奏分析（analysis/beat_candidates.py）。
- **本分镜按 120BPM 假设排**：1 beat = 15f，1 小节 = 60f，全片 30 小节；收尾峰值在第 27 小节线（1620f）之后。
- 镜界（帧）：0 / 180 / 285 / 375 / 495 / 585 / 660 / 750 / 870 / 960 / 1020 / 1200 / 1290 / 1380 / 1530 / 1620 / 1800 —— 全部为 15f 倍数；其中 180、660、1020、1380、1620 正好落在小节线（第 3、11、17、23、27 小节），作为幕界与重音位。
- BGM 实测后：镜界吸附真实瞬态 ±6f；**幕界（180/660/1020/1380/1620）与两处冲击必须落在最强 hit 上**；不得为卡点改叙事顺序。

## 2. 逐镜详细卡（16 镜）

> 每镜结构：画面 → 镜头与参数 → 主动作 → 文案槽位 → 转场 → SFX → 验收帧 → 风险/降级。卡名与 style-key 见 §1.3 主表；实现前必须读对应配方卡全文与 demo TSX（pipeline 阶段 5）。

### S01 · 夜桌·四格窗（0–180f，6.0s）

- **画面**：ink #18181b 夜场；2×2 窗格线（2px，violet-deep 低亮）从中心向外生长（0–25f）；四张白纸片分别落进四格：①订单行纹理（细横线+金额列）②七日格（11/5–11/11 手写感划痕）③乱序价格数字（124/257/621/760 散落）④**空白草稿纸**（留白，S02「收进一张视图」的伏笔，不能省）。三拍文字各 60f，逐词压印；caption 窗口 a f8–52 / b f68–112 / c f128–160（第三拍距冲白 ≥15f 收完）；f162–180 四格向中心收拢成一条白缝，星光在缝的中点第一次点亮。
- **镜头与参数**：固定正面 + 极缓推近（1.0→1.03，180f）；窗格线生长用 stroke 描画；纸片入场 y+24px/blur 6→0/rotate 2°，纸片浮动 ±6px（2 周期）；无相机抖动。
- **主动作**：四格窗成型 + 三拍文字 + 收拢（单一装置弧线，≥3s）。
- **文案槽位**：见主表（三组大字+caption，各 ≤8 字/行、≤18 字 caption）。
