# 手机首页风格样稿

打开 index.html 即可体验，无需安装依赖。英文默认，右上角可切换中文。产品名称和 App 图标均未决定；页面中的 `NAME TBD` 与问号图形是明确的占位内容。

## 当前交互

- 日期条可在触屏上左右滑动；点击日期更新日程。
- 示例日期只显示入住、退房等经营日程，不提供用户自定义待办。
- 日期改为圆形，选中态为深灰色，已有日程以圆点提示。
- 日程默认收起；上滑白色卡片顶部或点击展开，下滑或再次点击收起。鼠标滚轮在该区域也可操作。
- 经营一览包含并排的入住率图表与经营建议卡片，点击进入经营分析说明弹窗。图表为每周 70 可售间夜、49 已售间夜的示例数据，不是真实分析。
- 底部导航与任务入口打开说明弹窗，详细功能页面尚未制作。
- 所有经营信息均为示例。

## 设计说明

首页按后续参考图调整为浅蓝渐变背景与白色圆角卡片，结构为问候、圆形日期、可展开日程、经营一览双卡片和待处理事项。底部导航是平面的半透明磨砂胶囊，无边框、无阴影、无文字，保留屏幕阅读器标签。当前仅探索首页；经营分析页尚未制作。首页实现位于 home.css 与 home.js，由 index.html 加载。

产品面向手机，讨论文档使用中文，产品默认英文。日程是首页辅助模块，不改变咨询与评价、经营分析、内容推广三项核心功能的边界。尚未接入 AI、真实预订、OTA 或账号系统；这版用于确认首页风格，不代表完整课程产品已完成。

已检查：日期切换、横向滚动、语言切换、320px 窄屏无横向溢出及入口弹窗。
